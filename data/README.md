> v1.3 (2026-10-20): 국가코드 파일 하나로 통합(`공통_국가코드.csv`), 옛 국가코드 현대 통일, 파일명 띄어쓰기 금지, 국가쌍 데이터는 양방향 저장.
> v1.2 (2026-10-20): 단위표 키에 `지표` 추가, 파일 안 `단위` 열 허용, 제외사유 자유 서술로 변경, 사건ID 5자리 예외(E1), 연 단위 수치 파일 형식 명시.

## 1. 처리 순서

| 단계 | 할 일 | 핵심 규칙 |
| --- | --- | --- |
| 1 | 원본 보존 | 원본은 수정하지 않고 복사본으로 작업 |
| 2 | 데이터 유형 구분 | 사건형(1행 = 사건 1건) / 수치형(1행 = 국가 × 지표 × 연도) |
| 3 | 표 구조 정리 | 롱형식으로 통일. 구조상 안 되면 와이드로 두고 파일명에 `_wide` 표시 |
| 4 | 컬럼명 정리 | 한글, 띄어쓰기는 `_`, 단위는 열 이름에 붙이지 않음, 공통 이름으로 통일 |
| 5 | 1행 단위 정하기 | 미사일은 같은 시각·같은 장소의 여러 발 = 발사 1회 (시각이 없으면 같은 날짜·같은 장소) |
| 6 | 날짜·연도 정리 | `YYYY-MM-DD`, KST. 시각이 없으면 원본 날짜. 연도는 항상 채움 |
| 7 | 값 표기 통일 | 주체 코드, 결측, 숫자 타입. **값은 표준 단위로, 단위 정보는 `공통_단위.csv` 한 파일에** |
| 8 | 주체국·참여국 분리 | 사건 표에는 주체국 1개만. 여러 나라가 참여하면 참여국 표에 행으로 나눔 |
| 9 | 겹치는 열 정리 | 같은 값을 담은 열은 정리. 필수 컬럼은 예외 |
| 10 | 사건ID 부여 | `파일코드-네자리 번호`, 시작일 순 |
| 11 | 중복 처리 | 시작일 ±1일 + 같은 주체국 + 같은 사건 = 중복 |
| 12 | 사용 범위 표시 | 행은 지우지 않고 `사용여부`·`제외사유`로 구분 (나중에 추가) |
| 13 | 유형·카테고리 배정 | 팀 상의 후 결정 |
| 14 | 검증·기록 | 11번 체크리스트. 전처리 메모·항목정의서 작성 |

## 2. 표 구조와 PK

- [ ] **기본은 롱형식이에요.** 롱형식으로 바꿀 수 없는 표는 와이드로 두고, 파일명에 `_wide`를 붙여요.

| 표 | 1행 = | PK |
| --- | --- | --- |
| 사건 표 | 사건 1건 | `사건ID` |
| 수치 표 | 국가 × 지표 × 연도 | `국가 + 지표 + 연도` |
| 참여국 표 | 사건 1건 × 참여국 1개 | `사건ID + 참여국` |

**사건 표 예시** (PK = 사건ID)

| 사건ID | 시작일 | 종료일 | 연도 | 주체국 | 사건명 |
| --- | --- | --- | --- | --- | --- |
| A2-0153 | 2017-07-28 | 2017-07-28 | 2017 | PRK | 화성-14형 발사 |
| C4-0012 | 2003-08-27 | 2003-08-29 | 2003 | MUL | 제1차 6자회담 |

**수치 표 예시** (PK = 국가 + 지표 + 연도)

| 국가 | 지표 | 연도 | 값 |
| --- | --- | --- | --- |
| PRK | 경제성장률 | 2023 | 3.1 |
| KOR | 경제성장률 | 2023 | 1.4 |
| PRK | 경제성장률 | 2024 | 3.7 |

- `PRK + 경제성장률 + 2023` 조합은 표 안에 한 번만 나와야 해요.

**참여국 표 예시** (PK = 사건ID + 참여국)

| 사건ID | 참여국 |
| --- | --- |
| C4-0012 | KOR |
| C4-0012 | PRK |
| C4-0012 | USA |
| C4-0012 | CHN |
| C4-0012 | JPN |
| C4-0012 | RUS |

- `C4-0012 + KOR` 조합은 한 번만 나와야 해요. 사건ID는 여러 번 나와도 돼요.

(예시의 수치·날짜는 형식 설명용이에요.)

## 3. 컬럼명

- [ ] **한글**로 써요.
- [ ] **띄어쓰기는 `_`로 바꾸고, `·`, `()`, `/`는 빼요.**
- [ ] **열 이름에는 단위를 붙이지 않아요.** 예: `최고고도`, `국방예산액`, `증가율` (`최고고도_km` ✗). 단위는 `공통_단위.csv`에 따로 적어요. (아래 3-1)
- [ ] **뜻이 같은 열은 모든 파일에서 같은 이름을 써요.**

**사건 표 공통 열**

| 컬럼명 | 타입 | 뜻 |
| --- | --- | --- |
| 사건ID | String | 사건 식별번호 (PK) |
| 시작일 / 종료일 | Date | 사건 날짜 (KST) |
| 연도 | Integer | 시작 연도. 항상 채움 |
| 종료연도 | Integer | 연도 범위 데이터가 있는 파일에만 |
| 주체국 | String | 행동한 쪽 (코드 1개) |
| 대상국 | String | 상대 (코드 1개) |
| 사건명 | String | 사건 이름 |
| 요약 | String | 사건 설명 |
| 비고 | String | 날짜를 확인해서 바꾼 근거 등 특이사항 |
| 사용여부 / 제외사유 | String | 사용 범위 (나중에 추가) |

**수치 표 공통 열**

| 컬럼명 | 타입 | 뜻 |
| --- | --- | --- |
| 국가 | String | 주체 코드 |
| 지표 | String | 지표 이름 (예: 경제성장률) |
| 연도 | Integer | 기준 연도 |
| 값 | Float | 수치. 숫자만 넣고 단위는 `공통_단위.csv`에 기록 |

- [ ] **한 파일에 단위가 다른 지표를 같이 넣어도 돼요.** 단위 표가 `파일명 + 컬럼명 + 지표` 기준이라 지표마다 단위를 따로 적을 수 있어요 (예: D1_수출입액의 `수출_금액` 천달러 / `수출_증감률` pct).
- [ ] **연 단위 수치(인구·GNI·생산량 등)는 사건 표가 아니라 수치 표로 만들어요.** `시작일 = YYYY-01-01`, `종료일 = YYYY-12-31`처럼 날짜를 지어 넣지 않아요. 사건 표 모양(`주체국`·`항목`·`시작일`)으로 만든 파일은 `build_db.py`가 `주체국→국가`, `항목→지표`로 읽어 수치 표에 넣지만, 새로 만들 때는 처음부터 수치 표 열 이름을 써요.

**참여국 표 열**

| 컬럼명 | 타입 | 뜻 |
| --- | --- | --- |
| 사건ID | String | 사건 표와 연결 |
| 참여국 | String | 코드 1개 (`MUL` 사용 안 함) |

## 3-1. 값과 단위 분리 (모든 파일)

- [ ] **모든 파일에서 값과 단위를 분리해요.** 값 열에는 숫자만 넣고, 단위는 `공통_단위.csv` **파일 하나**에 모아 적어요.
- [ ] **값 파일의 숫자는 표준 단위(`표준_단위`)로 넣어요.** 예: 인구는 `명`, 금액은 `krw`·`usd`, 질량은 `t`. 원본이 천명·십억원이었어도 값 파일에는 명·원으로 환산해서 넣어요.
- [ ] **원본 단위로 보고 싶을 때만** `값 ÷ 환산_배수`를 해요. (천명으로 표시 → 값 ÷ 1000)
- [ ] **계산할 때는** 데이터 파일에 `공통_단위.csv`를 `파일명 + 컬럼명 (+ 지표)`로 join해요. 수치 표의 `값` 열은 지표마다 단위가 다를 수 있어서 `지표`까지 맞춰요. 사건 표의 숫자 열(최고고도 등)은 `지표`를 비워 두고 `파일명 + 컬럼명`만으로 join해요.
- [ ] **파일 안에 `단위` 열을 둬도 돼요.** 단, 그 값은 단위 표의 `표준_단위`와 같아야 해요 (`build_db.py`가 대조해요). 파일 안 `단위` 열은 보기 편하라고 두는 것이고, 원본 단위 환산은 항상 단위 표의 `환산_배수`로 해요.

**`공통_단위.csv` (PK = 파일명 + 컬럼명 + 지표)**

| 컬럼명 | 타입 | 뜻 |
| --- | --- | --- |
| 파일코드 | String | 예: `A2`, `D1` (참고용) |
| 폴더명 | String | 참고용 |
| 파일명 | String | 확장자 없는 전처리 파일명 (예: `F1_인구_정제`) |
| 컬럼명 | String | 전처리 후 열 이름 (예: `값`, `최고고도`). 단위 붙이지 않음 |
| 지표 | String | 수치 표에서 `값` 열의 지표 이름. 사건 표의 숫자 열은 빈칸 |
| 분류 | String | 통화 · 질량 · 인원 · 거리 · 비율 · 영양 · 개수 등 |
| 원본_단위 | String | 값 파일에 들어 있는 단위 (예: `천명`, `십억원`, `pct`) |
| 표준_단위 | String | 같은 분류끼리 맞출 단위 (예: `명`, `krw`) |
| 환산_배수 | Float | 원본 1단위 = 표준 단위 몇 개 (천명→명 = 1000). `값 ÷ 환산_배수` = 원본 단위 값. 원본=표준이면 1 |
| 비고 | String | 그 밖의 설명 |

| 파일명 | 컬럼명 | 지표 | 분류 | 원본_단위 | 표준_단위 | 환산_배수 |
| --- | --- | --- | --- | --- | --- | --- |
| D1_수출입액 | 값 | 수출_금액 | 통화 | 천달러 | usd | 1000 |
| D1_수출입액 | 값 | 수출_증감률 | 비율 | pct | pct | 1 |
| F1_인구_정제 | 값 | | 인원 | 천명 | 명 | 1000 |
| A2_미사일_발사_CSV | 최고고도 | | 거리 | km | km | 1 |

- [ ] **파일명에는 띄어쓰기를 쓰지 않아요.** `_`로 바꿔요 (예: `A2_미사일_발사_CSV`).
- [ ] **`파일명`을 키에 쓰는 이유:** 같은 파일코드 안에 `값` 열을 가진 파일이 여러 개라서(예: F1 11개) 파일코드만으로는 구분이 안 돼요. 파일명을 바꾸면 이 표도 같이 바꿔요.
- [ ] **헷갈리지 않기:** 단위 표에 `천명 → 명, 1000`이라고 적혀 있어도 값 파일의 인구는 `명` 숫자(`23934132`)예요. `원본_단위`는 "원래 자료가 무슨 단위였는지" 기록이고, 값에 배수를 또 곱하지 않아요.
- [ ] **숫자 열은 모두 단위 표에 한 행씩 있어야 해요.** 단위가 없는 열은 `개`·`회`·`건` 등 세는 단위를 적어요.
- [ ] **단위 표기는 하나로 통일해요.** 예: `%` ✗ → `pct` ✓
- [ ] **환산은 같은 분류 안에서만 해요.** 통화는 `krw`끼리, `usd`끼리 따로 맞추고, 원↔달러 환산은 환율 자료가 있을 때 따로 해요.
- [ ] **원본에 단위가 같이 적힌 값**(`"200 km"`)은 숫자만 남기고 단위는 단위 표에 옮겨요.
- [ ] **한 열 안에 단위가 섞여 있으면**(행마다 `km`, `m`이 다름) 먼저 한 단위로 환산한 뒤 숫자만 남겨요. 환산 내용은 전처리 메모에 적어요.

## 4. 날짜·연도

- [ ] **형식은 `YYYY-MM-DD`, 타입은 Date예요.** 모든 날짜는 KST 기준이에요.
- [ ] **시각이 있으면** KST로 변환해요. 날짜가 넘어가면 한국 날짜를 그대로 써요.
- [ ] **시각이 없으면** 원본 날짜를 써요.
    - 예외: 한국 쪽 근거로 실제 한국 날짜를 확인한 경우에만 바꾸고, `비고`에 근거를 적어요.
- [ ] **날짜를 지어내지 않아요.** 예: 연도만 있는 자료에 `2007-01-01`을 넣지 않아요.

| 데이터 | 시작일 | 종료일 | 연도 |
| --- | --- | --- | --- |
| 하루짜리 | 그날 | 시작일과 같음 | 시작일의 연도 |
| 여러 날 | 첫날 | 마지막 날 | 시작일의 연도 |
| 끝난 날을 모름 | 첫날 | Null | 시작일의 연도 |
| 월·연도만 있음 | Null | Null | 원본 연도 |
| 연도 범위 (1900~2000) | Null | Null | 1900 (`종료연도` 2000) |
| 모두 모름 | Null | Null | Null → 제외사유 `날짜 없음` |

- [ ] **일 단위 지수에는 시작일이 있는 행만 넣어요.** 시작일이 Null이고 연도만 있는 행은 연도별 표시에만 써요. (예: B2 무기이전은 전부 연도만 있어서 연 단위로만 봐요.)

## 5. 주체 코드

| 구분 | 코드 |
| --- | --- |
| 주요 국가 | `KOR` 한국 · `PRK` 북한 · `USA` 미국 · `CHN` 중국 · `JPN` 일본 · `RUS` 러시아 · `TWN` 대만 |
| 연합 | `KOR_USA` 한미연합 |
| 국제기구 | `UN` · `NATO` · `EU` 등 (실제로 나오는 것만 목록에 추가) |
| 다자 | `MUL` (주도국이 없는 다자 사건, 주체국 열에서만 사용) |
| 그 밖의 국가 | ISO 3자리 코드 (예: `AUS`), 목록에 추가 후 사용 |

- [ ] **모두 대문자로 써요.**
- [ ] **목록에 없는 코드는 쓰지 않아요.** 목록은 `공통_국가코드.csv` 한 파일이에요 (주요 국가·연합·국제기구·MUL·OTH + ISO3 전체, 열: `코드, 이름, 구분`). 없는 코드가 필요하면 여기에 먼저 추가해요.
- [ ] **옛 국가는 현대 국가 코드로 통일해요.** 예: 동독·바이에른 → `DEU`, 체코슬로바키아 → `CZE`, 남베트남 → `VNM`, 유고 → `SRB`, 자이르 → `COD`. 통일하면서 같은 해에 같은 키가 겹치면 원래부터 현대 코드였던 행을 남기고 나머지는 지워요. "독일-독일"처럼 자기 자신과의 쌍이 생기면 지워요.
- [ ] **소련은 `RUS`로 써요.**

## 6. 주체국·참여국

| 경우 | 주체국 (사건 표) | 참여국 표 |
| --- | --- | --- |
| 한 나라의 행동 | 그 나라 (예: `PRK`) | 넣지 않음 |
| 한미연합 | `KOR_USA` | KOR, USA |
| 양자 회담 (예: 북중) | 주도한 쪽 (예: `PRK`) | PRK, CHN |
| 다자 (예: 6자회담) | `MUL` | 참여국마다 1행 |
| 국제기구 | `UN` 등 | 필요하면 회원국 |

- [ ] **국가 × 상대국 쌍 데이터(동맹유사도 등)는 양방향으로 저장해요.** `USA, KOR`이 있으면 `KOR, USA`도 같은 값으로 넣어요. 한쪽만 있으면 한국 기준으로 조인할 때 절반이 빈칸이 돼요.
- [ ] **사건 표에는 주체국 1개만 적어요.** 한 칸에 여러 값을 넣지 않아요.
- [ ] **참여국 표에는 참여국이 2개 이상인 사건만 넣어요.**
- [ ] **주체국이 `MUL`인 사건은 참여국 표에 반드시 2행 이상 있어야 해요.**
- [ ] **주체국이 없는 파일은 열을 추가하고 행마다 값을 넣어요.**

---

## 7. 값·타입

- [ ] **결측:** 모르는 값은 Null, 없었던 것은 0이에요. 0은 건수·수량처럼 세는 값에만 써요.
    - `Unknown`, `?`, `...`, `-`는 모두 Null로 바꿔요.
- [ ] **숫자:** 계산하는 숫자만 Integer·Float로 바꿔요. 빈칸이 있는 정수 열은 `Int64`로 해요.
- [ ] **ID·코드:** 숫자 모양이어도 String이에요.
- [ ] **단위가 섞인 문자열은 숫자로 바꿔요.** 예: `"200 km"` → `200` (단위 `km`는 `공통_단위.csv`에 기록)

---

## 8. 겹치는 열

- [ ] **같은 값을 담은 열은 정리해요.** 예: 원본날짜와 시작일
- [ ] **필수 컬럼은 정리하지 않고 남겨요.**

---

## 9. 사건ID (PK)

| 항목 | 규칙 |
| --- | --- |
| 형식 | `파일코드-네자리 번호` (예: `A3-0001`). 한 파일이 1만 건을 넘으면 다섯 자리 (예: `E1-00001`) |
| 순서 | 시작일 순. 같은 날이면 원본 파일 순서. 시작일이 없는 행은 연도 순으로 뒤에 붙임 |
| 고정 | 한 번 붙인 번호는 바꾸지 않아요. 새 행은 다음 번호를 받아요 |

---

## 10. 사용여부·제외사유 (나중에 추가)

- [ ] **사용여부:** `Y` / `N`
- [ ] **제외사유:** 정해진 규격 없이 짧게 써요 (예: `중복`, `날짜 없음`, `대상 외`, `C5-0063과 같은 조치`). 집계는 `사용여부`로만 하고 `제외사유`는 사람이 읽는 용도예요.
- [ ] **행은 지우지 않아요.** 사용하지 않는 행은 `N`으로 표시만 해요.

---

## 11. 검증 체크리스트

- [ ] 사건ID 중복 없음, 빈칸 없음
- [ ] 종료일 ≥ 시작일
- [ ] 연도 = 시작일의 연도 (시작일이 있는 행)
- [ ] 주체국·참여국 값이 코드 목록 안에 있음
- [ ] 주체국 = `MUL`이고 `사용여부 = Y`인 사건은 참여국 표에 2행 이상
- [ ] 참여국 표의 사건ID가 모두 사건 표에 있음
- [ ] 참여국 표의 `사건ID + 참여국` 중복 없음
- [ ] 수치 표의 `국가 + 지표 + 연도` 중복 없음
- [ ] 원본 행 수 = 전처리 행 수 (삭제 없음)
- [ ] 열 이름에 단위(`_km`, `_pct` 등)가 붙어 있지 않음
- [ ] 숫자 열마다 `공통_단위.csv`에 `파일명 + 컬럼명 (+ 지표)` 행이 있음
- [ ] `공통_단위.csv`의 `파일명 + 컬럼명 + 지표` 중복 없음, 원본_단위·표준_단위·환산_배수 빈칸 없음
- [ ] 파일 안에 `단위` 열이 있으면 단위 표의 `표준_단위`와 같음
- [ ] 단위 표기가 통일돼 있음 (`%`와 `pct`가 섞여 있지 않음)
- [ ] 숫자 열에 단위 문자가 섞여 있지 않음 (숫자 타입)
