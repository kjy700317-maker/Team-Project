## 1. 새 함수 (F6, `utils/loader.py` 끝 — 모두 `st.cache_data`)
| 함수 | 돌려주는 것 | 주요 열 |
|---|---|---|
| `load_tension_basic(scenario="기본")` | 비교선 일별 | `날짜` · `T_원값`·`T_표시7일`(주 지수) · `T_basic`·`T_basic_표시7일`(비교선) · `차이_표시7일` |
| `load_tension_basic_stats(scenario)` | 비교선 요약(항목·값) | 주 지수와 상관 · 차이 최대·중앙 · 상승 묶음 평소값 |
| `load_tension_normalization_figure(scenario)` | "묶음 정규화 효과" 그림(Plotly) | 위 = 주 지수 vs T_basic(7일 평균), 아래 = 차이 |
| `load_tension_gpr(scenario)` | 봉수 vs GPR 월별 | `연월` · `봉수_T평균` · `GPR`(%) · `봉수_순위%` · `GPR_순위%` · `순위차` |
| `load_tension_gpr_stats(scenario)` | GPR 비교 요약(항목·값) | 비교 기간 · 달 수 · 피어슨 상관 · 순위 상관 |
| `load_tension_gpr_figure(scenario)` | GPR 비교 그림(Plotly) | 순위%(0~100) 두 선, 원값은 마우스를 올리면 |
| `load_tension_half_life(scenario)` | 반감기 민감도 표 | `반감기`(7·14·21·30) · `T구간` · `1거%`~`5거%` · `기준 반감기와 단계 같은 날%` · `한 단계 안%` · 위기 10건 단계 · `현재` |
| `load_tension_month_events(month, scenario="기본", top=3)` | 그달 주요 사건(month = "YYYY-MM") | `날짜` · `사건ID` · `요소` · `묶음` · `구분` · `S` · `주체국` · `사건명` |
- 문구 상수는 `utils/tension/screen.py`에 있습니다: `HALF_LIFE_NOTE`(반감기 설명 4문단) · `NORMALIZATION_NOTE`(비교선 판독문 1줄) · `GPR_NOTES`(GPR 판독문 3줄) · `GPR_SOURCE`(GPR 출처 한 줄).
