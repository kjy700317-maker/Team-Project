## 0. 한 줄 요약
사용자가 **"지나간 사건을 얼마나 오래 기억할지 · 남북 회담이 긴장을 얼마나 누그러뜨릴지 · 무엇을 더 무겁게 볼지"**를 슬라이더로 바꾸면, 앱이 그 자리에서 긴장도를 다시 계산해 **공식 결과와 나란히** 보여 주는 화면입니다. 공식 결과(지금 화면들)는 그대로 둡니다.

## 1. 정해진 것 (10-30 사용자 결정)
| 항목 | 결정 |
|---|---|
| 슬라이더로 여는 값 | ① 반감기 ② 완화 세기 c · 완화 상한 κ ③ 묶음 비중 ω(핵·미사일 · 군사 과시 · 위협 언어·교리) — 사건 기본점수 B는 열지 않음 |
| 이름 붙이는 방식 | 기호(ω, c, κ)나 "가중 +/−"가 아니라 **그 값이 뜻하는 것을 늘리고 줄인다는 게 보이게**(아래 2절 문구) |
| 단계 구간 | 슬라이더 값마다 **다시 뽑음**(규칙 = 기준기간 2010~2019의 70·90·95·98분위, ADR-018). 그래서 구간 숫자도 바뀜 — 화면에 보여 줌 |
| "공식 결과가 아님" 표시 | **기본값과 다를 때만** 표시. 모두 기본값이면 공식 결과와 같음(긴장도 담당이 테스트로 고정) |
| 공식 결과 | 지금 화면(홈·1~4페이지)은 그대로 공식 결과(`load_tension_*`)만 씀 |

## 2. 슬라이더 3종 — 이름·설명 문구 (범위 확정 10-30 사용자 · 이름·문구는 제안)
| 무엇 | 화면 이름(제안) | 설명 한 줄(제안) | 범위 · 기본 | 올리면 / 내리면 |
|---|---|---|---|---|
| 반감기 | **지나간 사건을 얼마나 오래 기억할까** | "14일 = 사건 점수가 2주 뒤 절반, 4주 뒤 4분의 1로 줄어듭니다" (숫자는 고른 값에 맞춰) | 7~30일 · 14 | 올리면 큰 사건의 여파가 오래 남음 / 내리면 최근 사건에만 민감 |
| 완화 세기 c | **남북 회담이 긴장을 얼마나 누그러뜨릴까** | "회담 기록이 있을 때 긴장도를 깎는 힘의 세기" | 0~0.3 · 0.1 | 0이면 회담을 전혀 반영하지 않음 |
| 완화 상한 κ | **회담으로 최대 몇 %까지 누그러뜨릴 수 있나** | "회담이 아무리 많아도 이 비율 이상은 깎지 않습니다" | 0~80% · 50% | |
| 묶음 비중 ω | **무엇을 더 무겁게 볼까** (묶음마다 슬라이더 1개, 3개) | 묶음 옆에 뜻을 함께: 핵·미사일 = "미사일 발사·핵실험 같은 무기 행동" · 군사 과시 = "훈련·열병식·전력 전개 같은 힘 과시" · 위협 언어·교리 = "성명·담화·교리 변경 같은 말로 하는 위협" | 묶음마다 0.5~2배 · 1배(보통) | 그 묶음 사건이 많던 시기가 더 높게 / 더 낮게 나옴 |
- 묶음 비중은 **세 슬라이더 값을 합이 100%가 되게 바꾼 "지금 비중"**을 막대 하나(또는 띠)로 같이 보여 주세요. 예: 핵·미사일 2배 → "핵·미사일 50% · 군사 과시 25% · 위협 언어·교리 25%". 기본은 셋 다 1배 = 33%씩(지금 공식 결과).
- (선택) 빠른 선택 버튼: "균형(기본)" · "행동 중시(말 위협 0.5배)" · "핵·미사일 중시(핵·미사일 2배)".
- 바뀌지 않는 것(화면에 작게 안내): 물리 충돌·북러 밀착·핵실험/ICBM 당일 하한, 하강 7일 규칙, 기준기간 2010~2019, 사건 점수 S.

## 3. 화면 구성 제안 (배치·디자인은 담당자께서 정해 주세요)
- 자리: **새 페이지 `pages/5_가정_바꿔보기.py`**(제안 — 공식 화면과 섞이지 않게) 또는 1페이지 아래 접는 상자. 어느 쪽이 좋은지 알려 주세요.
- 위: 슬라이더 영역 + **"기본값으로 되돌리기"** 버튼.
- 표시: 값이 기본과 다르면 상단에 **"공식 결과가 아닙니다 — 가정을 바꿔 다시 계산한 결과입니다"**.
- 그림: 공식 7일 표시선 vs 내 설정 7일 표시선을 한 그림에 겹쳐서(공식 = 회색, 내 설정 = 단계 색 등). 아래 단계 띠도 두 줄(공식 / 내 설정)이면 차이가 잘 보입니다.
- 비교 표(공식 · 내 설정 두 열): 현재 단계 · 평소 대비(7일) · 단계 구간(예: "115/256/315/378 → 111/251/302/342") · 1~5거 날 비율 · 위기 10건 단계 · **공식과 단계가 같은 날 %**.
- 문구: "단계 구간은 규칙(평소 기간의 70·90·95·98%)대로 다시 뽑았습니다 — 그래서 5거 비율은 크게 바뀌지 않고, 어느 날이 몇 거인지가 바뀝니다."

## 4. 함수 (예정 — F8에서 만듦, 이름·열은 확정본에서 바뀔 수 있음)
| 함수(예정) | 돌려주는 것 |
|---|---|
| `load_tension_recompute(half_life=14, relief_c=0.1, relief_cap=0.5, weights=None, scenario="기본")` | (일별 표 — `load_tension_daily()`와 같은 열, 요약 — 단계 구간·1~5거 %·위기 10건 단계·공식과 같은 날 %·`공식과_같음`) · `weights` = `{"핵·미사일": 1, "군사 과시": 1, "위협 언어·교리": 1}` 꼴(배수) |
| `load_tension_recompute_figure(…같은 인자)` (검토 중) | 공식 vs 내 설정 그림(Plotly) — 화면에서 직접 그리셔도 됨 |
- 기본값은 config에서 읽음(`HALF_LIFE_DAYS` 14 · `RELIEF_C` 0.1 · `RELIEF_CAP` 0.5). 한 번 계산 약 0.05초(클라우드 측정, 10-30) — `st.cache_data`라 같은 값은 다시 계산하지 않음.
- 기존 config 이름 15개와 `load_tension_*` 함수는 바꾸지 않습니다.
