## 0. 한 줄 요약
사용자가 **"지나간 사건을 얼마나 오래 기억할지 · 남북 회담이 긴장을 얼마나 누그러뜨릴지 · 무엇을 더 무겁게 볼지"**를 슬라이더로 바꾸면, 앱이 그 자리에서 긴장도를 다시 계산해 **공식 결과와 나란히** 보여 주는 화면입니다. 공식 결과(홈·1~4페이지)는 그대로 둡니다.

## 1. 정해진 것
| 항목 | 결정 |
|---|---|
| 자리 | **새 페이지 `pages/5_가정바꿔보기.py`(이름은 담당자께서 정함)** — 발표 때 "여기부터는 가정"으로 구분(박성인 님 10-30) |
| 배치 | **왼쪽 조절판 · 오른쪽 결과**(박성인 님 10-30) |
| 여는 값 | 반감기 · 완화 세기 c · 완화 상한 κ · 묶음 비중(핵·미사일 · 군사 과시 · 위협 언어·교리) — 사건 점수는 열지 않음 |
| 이름 | **짧은 이름 + 도움말 따로**(박성인 님 10-30) — 아래 2절은 제안, 뜻만 같으면 고치셔도 됩니다 |
| 단계 구간 | 슬라이더 값마다 같은 규칙(평소 기간 2010~2019의 70·90·95·98%)으로 **다시 뽑음** → 구간 숫자도 바뀜 |
| "공식 결과가 아님" | **기본값과 다를 때만** 표시(`정보["공식과_같음"]`이 False일 때). 모두 기본값이면 공식 결과와 같음(테스트로 고정) |

## 2. 슬라이더 — 짧은 이름 · 범위 · 도움말 (제안)
| 값 | 짧은 이름(제안) | 범위 · 기본 · 단계(제안) | 도움말(제안) |
|---|---|---|---|
| 반감기 `half_life` | **기억 기간** | 7~30일 · 14 · 1일 | "지나간 사건 점수가 절반으로 줄어드는 날수입니다. 14일이면 2주 뒤 절반, 4주 뒤 4분의 1. 늘리면 큰 사건의 여파가 오래 남고, 줄이면 최근 사건에만 민감해집니다." |
| 완화 세기 `relief_c` | **회담 효과** | 0~0.3 · 0.1 · 0.01 | "남북 회담 기록이 있을 때 긴장도를 깎는 힘의 세기입니다. 0이면 회담을 전혀 반영하지 않습니다." |
| 완화 상한 `relief_cap` | **회담 효과 상한** | 0~0.8 · 0.5 · 0.05 (화면은 0~80%로 보여 주고 함수에는 0~0.8로) | "회담이 아무리 많아도 이 비율 이상은 깎지 않습니다." |
| 묶음 비중 `weights` | **무게: 핵·미사일 / 군사 과시 / 위협 언어·교리** (묶음마다 1개, 3개) | 묶음마다 0.5~2배 · 1배 · 0.1 | 묶음 뜻: 핵·미사일 = "미사일 발사·핵실험 같은 무기 행동" · 군사 과시 = "훈련·열병식·전력 전개 같은 힘 과시" · 위협 언어·교리 = "성명·담화·교리 변경 같은 말로 하는 위협". "올리면 그 묶음 사건이 많던 시기가 더 높게 나옵니다." |
- 비중 막대: 함수가 돌려주는 `정보["비중%"]`(합 100%)를 막대 하나로 보여 주세요. 예: 핵·미사일 2배 → 50 · 25 · 25%. 기본은 33.3%씩.
- (선택) 빠른 선택 버튼: "균형(기본)" · "행동 중시(위협 언어·교리 0.5배)" · "핵·미사일 중시(핵·미사일 2배)".
- **"기본값으로 되돌리기"** 버튼(값: 14 · 0.1 · 0.5 · 모두 1배).
- 바뀌지 않는 것(작게 안내): 물리 충돌·북러 밀착·핵실험/ICBM 당일 하한, 하강 7일 규칙, 평소 기간 2010~2019, 사건 점수.

## 3. 함수 (develop — `utils/loader.py` 끝, `st.cache_data`)
```python
from utils.loader import load_tension_recompute
import config

daily, table, info = load_tension_recompute(
    half_life=14,            # None이면 config.HALF_LIFE_DAYS(14)
    relief_c=0.1,            # None이면 config.RELIEF_C(0.1)
    relief_cap=0.5,          # None이면 config.RELIEF_CAP(0.5) — 0~0.8(비율)
    weights={"핵·미사일": 1, "군사 과시": 1, "위협 언어·교리": 1},   # 빠진 묶음 = 1배, None = 모두 1배
    scenario="기본",
)
```
| 돌려주는 것 | 모양 |
|---|---|
| `daily` | **`load_tension_daily()`와 같은 열**(날짜·T_원값·T_표시7일·…·평소대비·최종단계·단계이름·화면_단계문구·완화할인_δ 등) — 기존 1페이지 그림 코드를 그대로 쓸 수 있음 |
| `table` | 비교 표 20행, 열 `항목 · 공식 · 내 설정`(값은 글자): 현재 단계 · 평소 대비(7일) · 단계 구간 · 1~5거 날 % · 공식과 단계 같은 날 % · 공식과 한 단계 안 % · 위기 10건 단계 |
| `info` | dict: `공식과_같음`(bool) · `설정` · `비중%`({묶음: %}) · `구간`(내 설정 4개) · `공식_구간` · `같은날%` · `한단계안%` |
- 범위: `config.SLIDER_HALF_LIFE` (7, 30) · `SLIDER_RELIEF_C` (0, 0.3) · `SLIDER_RELIEF_CAP` (0, 0.8) · `SLIDER_WEIGHT` (0.5, 2.0) — 슬라이더 min·max에 이 값을 쓰면 숫자를 두 곳에 적지 않아도 됩니다. **범위 밖 값은 `ValueError`**.
- 공식 결과(비교선)는 기존 `load_tension_daily()`로 그리면 됩니다.
- 계산 한 번 약 0.2~0.4초 — 같은 값은 캐시라 다시 계산하지 않습니다.

## 4. 화면 구성 제안 (오른쪽 결과 영역 — 디자인은 담당자께서)
- 맨 위: `info["공식과_같음"]`이 False면 **"공식 결과가 아닙니다 — 가정을 바꿔 다시 계산한 결과입니다"**.
- 그림: 공식 7일 표시선(`load_tension_daily()["T_표시7일"]`, 회색) vs 내 설정(`daily["T_표시7일"]`)을 겹쳐서. 아래 단계 띠 두 줄(공식 / 내 설정)이면 차이가 잘 보입니다.
- 비교 표: `table` 그대로(`st.dataframe(table, hide_index=True)`).
- 문구: "단계 구간은 같은 규칙(평소 기간의 70·90·95·98%)으로 다시 뽑았습니다 — 그래서 5거 비율은 크게 바뀌지 않고, 어느 날이 몇 거인지가 바뀝니다."
- 확인용 숫자(끝날 2026-10-29, 기본): 기본값 → 구간 115/256/315/378 · 같은 날 100% / 기억 기간 21 · 회담 효과 0.2 · 상한 30% → 111/251/302/342 · 같은 날 90.8% / 핵·미사일 2배 → 116/267/330/392 · 같은 날 83.0%.
