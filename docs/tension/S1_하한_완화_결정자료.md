## 1. 이번에 새로 확인한 사실 `[우리 데이터]`

1. **2022~2024년에는 물리 하한이 최종 단계를 거의 바꾸지 않는다.** 이 시기는 T 자체가 4~5거다(2024년 5거 159일은 하한이 없어도 159일). 2024년 단계 분포는 (a) 1·2·3·4·5거 = 0·27·72·108·159일, (c)·(e) = 3·32·71·101·159일 — 차이 7~8일. 하한이 실제로 단계를 정하는 곳은 **2010·2014·2015·2025·2026년**이다. → "오물풍선을 몇 거로 보나"는 지금 수치보다 **단계의 뜻과 앞으로의 견고성**(S2 점수·A2 연장으로 2024 T가 낮아질 때) 문제다.

3. **A3–A7 중복 1쌍**: 2024-10-15 경의·동해선 도로 폭파가 A3-0059(S 4.0)와 A7-0120(S 5.25)에 같은 문장으로 들어 있다 `[원문]`. 30일 원점수가 9.25로 이중 계산된다. → 보류 6번(A3–A7 중복)으로 넘김. 이번 계산에서는 고치지 않았다.

### 2.1 후보 (모두 30일 원점수 R = Σ exp(−k²/200)·d, ADR-006 2번 유지)

| 후보 | 규칙 |
|---|---|
| (a) 현행 | R_물리(A3+A7) ≥ 3 → 최소 3거, ≥ 6 → 최소 4거, 5거 없음 |
| (b) 문턱 상향 | ≥ 4 → 3거, ≥ 7 → 4거 (풍선 1건으로는 안 켜짐) |

| **(e) 추가안** | **풍선 외(A7 + A3 중 무인기·DMZ 침범·도로 폭파) 3·6 / 오물풍선만 R_풍선 ≥ 6 → 3거까지 / 사망·침몰 사건 당일 5거 판정** |
| 민감도 d′ | (a) + 사망·침몰 당일 5거 (= (e)에서 풍선 분리를 뺀 것) |
| 민감도 c′ | 풍선만 분리 (= (e)에서 교전 하한을 뺀 것) |

### 2.5 권장: (e) — 이유
1. 위기 세 건(천안함·연평도·목함지뢰)의 4거 이상을 모두 유지한다. (b)는 천안함·목함지뢰를 3거로 낮춘다(천안함 S 6.0은 간이 판정 한계 — 1절 2번).
2. 사망·침몰 2건(2010)만 5거가 된다. 지금 구조(ADR-007)에서는 물리 충돌이 T에 들어가지 않아, 연평도 포격(사망자 발생)이 최고 4거에 머물고 미사일 집중기는 5거가 된다. 봉수 5거 "교전"의 뜻과 어긋난다 `[해석]`.
3. 풍선은 최대 3거. (c)처럼 A3 전체를 묶어 누르면 2022-12 무인기 서울 상공 침입(S 5.0)과 단독 DMZ 침범(2025-10-23·11-19, S 4.0)이 하한을 못 켜고, 2024-06 DMZ 침범 3건 연속도 3거에서 멈춘다(경계 침범인데 4거가 안 됨). (e)는 풍선만 누른다. 풍선 1건(S 3.0)은 안 켜지고, 같은 날 2건 또는 며칠 사이 3건 이상이면 3거.
4. 전체 영향은 작다: 하한이 판정을 올린 날 306 → 294, 5거 비율 14.2 → 14.4%, 단계 바뀜 22.9 → 23.2/년.

**알려진 대가**: 규칙이 3줄이 된다(설명 부담). "사망·침몰"은 지금 요약 키워드로 판독한 2건이라, 앞으로 사건이 생기면 **사람이 판정**해야 한다. 풍선 분리는 요소(A3)가 아니라 **사건 종류(`사건명` Balloon)** 기준이다.

### 3.4 권장: c = 0.1 유지 — 이유
1. c는 "몇 점짜리 회담부터 최대 할인을 주나"를 정하는 손잡이다. 0.1이면 그 선이 S_보정 3.79 = **장성급(4) 이상 정치·군사 회담**이다. "경제·사회 교류는 조금, 군사 실무는 절반 가까이, 장성급·고위급·정상은 최대"라는 서열에 가장 잘 맞는다 `[해석]`.
2. 대형 위협 사건을 오래된 작은 회담이 덮지 않는다: 4차 핵 3거 유지(c ≥ 0.5면 2거). 연평도 T 136(c = 1이면 96).
3. 2018 국면에서는 c = 0.1 이상 모두 상한 — 완화 효과가 큰 해에는 충분히 크게 작동한다.
4. 0.2와 차이: 0.2면 군사 실무(3.0)도 10일 상한, 4차 핵은 3거지만 T 168로 문턱 150에 더 가깝고, H3를 Y로 둘 경우 4차 핵이 2거로 떨어진다(4.3절).

### 3.5 ADR-008 정리 문장 초안 (결정 후 반영)
> **ADR-008 완화 처리 = 수정자(곱)** — 지수 = 상승 지수 × (1 − min(**c** × 완화 원점수 ÷ 완화 평소값, 0.5)), **c = 0.1**, cap = 0.5.
> *2026-10-27 갱신:* 10-26 기록의 식(c = 1, "완화 평소 대비 ÷ 100")은 회담 1건이 수 주간 상한(50%)에 붙는 문제가 있어 v0.1부터 c = 0.1로 계산해 왔다. 이번에 이를 확정한다. c는 "당일에 상한에 닿는 최소 회담 점수"(= 0.5 × B_완 ÷ c, 지금 3.79 = 장성급 이상 정치·군사 회담)를 정한다. 분야 보정(ADR-015, 5:1)과 함께 경제 실무 당일 5%, 군사 실무 40%, 장성급 이상 50%. 근거: `claude/S1_하한_완화_결정자료.md` 3절.

## 5. 세 결정이 서로 얽히는 곳 (v0.1.3 계산 때 주의)
- **H2 × H3**: 4차 핵 단계가 둘의 조합으로 정해진다. c = 0.1·N → 3거(T 176), c = 0.1·Y → 3거(153), c = 0.2·Y → 2거, c ≥ 0.5 → 2거 이하.
- **H1 × S2(점수)**: 천안함 S(지금 6.0)와 A7 피해 계수가 바뀌면 (b)의 평가가 바뀐다. 문턱 3·6은 A7 B 6 기준이라 팀 A7 점수가 들어오면 2.3절 표를 다시 뽑아 점검.
- **H2 × S3(기준기간)**: B_완이 기준기간에 따라 바뀐다(3.6절).
- **E5 하한(4·10)은 바꾸지 않았다.** 2.3절 비교에서 물리와 E5의 "큰 단독 사건 = 약 2주 3거" 일관성은 유지된다.
