## 1. 한 줄 정의
**긴장도 = 최근 14일 반감기로 쌓은 사건 점수를 "평소(2010~2019 평균) = 100"으로 나눈 값이다.** 관측된 사건의 누적 강도를 재는 지수이고, 앞날을 예측하지 않는다(ADR-001). 단계(봉수 1~5거)는 이 값이 평소보다 얼마나 드문 수준인지와, 물리 충돌·북러 밀착·핵실험·ICBM 같은 사건이 있었는지 중 높은 쪽을 따른다(ADR-018).

## 2. 계산 흐름
```
사건 1건                일 합                 감쇠 누적              평소 대비              합치기
S = B × C   →   d(묶음 g, 날 t)   →   R = λR₋₁ + d   →   T_g = 100·R_g/B_g   →   T⁺ = 상승 묶음 평균
 ①                  ②                    ③                  ④⑤                      ⑥
                                                                                      │
                          완화(남북 회담) R완 → δ = min(c·R완/B완, κ)  ⑦  ─────────→  T = T⁺·(1−δ)  ⑧
                                                                                      │
   ┌──────────────────────────────────────────────────────────────────────────────────┤
   │ T 구간 단계 L^T  ⑨  (기준기간 T의 70·90·95·98분위)                                  │
   │ 전용 하한 F^물·F^E5, 사건 하한 F^사  ⑩  (반가우스 30일 원점수·사건 당일)            │
   └─────────→  판정 J = max(L^T, F^물, F^E5, F^사)  ⑪  →  최종 단계 L (올릴 땐 즉시, 내릴 땐 7일마다 한 단계)  ⑫
                                                                                      │
   표시: T̄ 7일 평균 ⑬ · 그날까지 상위% ⑭ · 원점수 게이지 ⑮ · 14일 변화 ⑯ · 카드 문구 ⑰ · 비교선 ⑮′
```
- 원점수(상승 묶음 R의 합)는 **게이지로만** 보여 주고 단계 판정에 쓰지 않는다(ADR-018).
- 물리 충돌·북러 밀착은 평소 대비(④⑤)에서 빼고 전용 하한(⑩)으로만 단계에 반영한다. 기준기간 사건이 11~13건뿐이라 평소값이 0에 가깝고, 사건 1건에 평소 대비가 수천으로 튀기 때문이다(ADR-007).

## 3. 식 ①~⑰ · ⑮′ (기호는 아래 표 → 파라미터는 4절)

| 기호 | 뜻 |

- **한 번에 계산:** `core.daily_table(events, days, bundles, type4_ids, params)`가 ②~⑰과 일별 CSV의 모든 열을 만든다. `params`로 파라미터를 바꿀 수 있다(20개 키 `core.PARAM_KEYS`) — 반감기 민감도와 비교선이 이것을 쓴다.
- **구간은 값이 아니라 규칙이다.** 115/256/315/378은 기준기간 T에서 ⑨로 뽑은 결과이고, 점수·기준기간·반감기가 바뀌면 같은 규칙으로 다시 뽑는다. 정수로 반올림한 값으로 판정한다(표에 보이는 문턱 = 실제 문턱).
- 사건 1건이 T에 더하는 몫: `ΔT = 100·S·λ^k / (|G|·B_g) · (1−δ)` (k = 며칠 전인가). 평소값 B_g가 작은 묶음일수록 1점이 크다 — ÷B_g의 의도(미사일 묶음 독주 방지)이자 주의점이다.

## 9. 알려진 한계 (화면 각주·판독문과 같은 내용)
- **기본점수 B는 근거 자료 없이 정한 판단이다**(ADR-004, 사용자 확인 10-28). B·묶음 가중을 ±50% 흔들어도 일별 단계 86~91%가 같다(v0.1.4 M5, ADR-004). 약한 곳: 목함지뢰 4거 55% → 4거 유형 규칙(판정표)으로 보강했다.
- **2022년 이후 기록 밀도가 기준기간의 2~5배**라 그 시기는 높게 나온다(2023년 4거 이상 60%). 반대로 **2020~2021은 실제 소강기이면서 일부 요소 기록이 적어** 낮게 나올 수 있다.
- **A2 미사일 자료가 2024-11-05에서 끝난다.** 그 뒤 핵·미사일 묶음은 A1·B1만으로 움직이고 ICBM 사건 하한이 없다. 이 구간의 0은 실제 0이 아니라 자료 없음이다(`A2자료` 열 · 화면에 표시). 연장은 팀 작업(보류).
- 자료 충실도: A3는 2022년부터 수집 · A7은 2020-05-03 철원 GP 총격 미포함 · C1은 2021년 기록 없음 · A5는 2018~2021 기록 없음(팀: 그대로 진행).
- 반감기 14일의 대가: 단독 핵실험이 2거에 그친다 → 사건 하한(핵실험·ICBM 당일 3거)으로 보완. 반감기 7·21·30일 민감도는 `반감기_민감도.csv`로 공개한다.
- 하강 규칙의 대가: 5거에서 1거까지 내려오는 데 최소 28일이 걸린다.
- 완화 할인이 상한 κ에 붙는 날이 272일(2018년 237일 · 2014년 25일 · 2015년 10일). 단계에는 영향이 없고 2018년 선 높이만 바꾼다.
- 북미 정상외교·국내 정치 사건은 지수 밖이다 — 완화는 남북 회담만. GPR 한국과 달라지는 달(2018 정상회담기 등)은 "행동 vs 관심"의 설계상 차이다.
- 외부 대조(내부용): CrisisWatch(International Crisis Group) 악화 판정 달의 85%에서 봉수 2거 이상, 방향 쌍 63~69% 일치. 앱 게재는 Crisis Group 허락 확인 필요(보류).
- **자료 이상은 0점으로 두지 않고 계산을 멈춘다**(ValueError): 계산 기간이 기준기간 2010-01-01~2019-12-31을 다 담지 않음(끝날 < 2019-12-31 또는 시작일 > 2010-01-01) · 평소값 B_g ≤ 0 · 첫 문턱 θ₁ ≤ 0 · 판정표 4거 유형·사망 사건ID가 사건표에 없음 · 사건표 열 이름·순서 불일치(결측·형식 오류·중복 행은 `load_events`가 빼고 계속한다 — `run_tension`은 그 수를 `load 제외 N`으로 출력할 뿐 파일로 남기지 않는다).
- 반올림: 분위가 정확히 x.5이면 짝수 반올림이 의도와 다를 수 있어 요약의 `경계_x.5_주의`가 True가 된다 — 사람이 확인.
