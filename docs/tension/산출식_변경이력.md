## 1. 이름·역할·학습

### C01 지수 이름 = "긴장도"
- 처음: P1 "긴장 지수", P2 초안에서 "위험도"도 후보.
- 지금: "긴장도". **왜:** "위험도"는 일어날 가능성(예측)으로 읽힘(ADR-001) — 교수 피드백의 "예측" 표현 문제와 다시 부딪힘(P2 0절). 계산하는 것은 확률이 아니라 관측된 사건의 누적 강도. GPR 저자들도 "risk" 이름이 부정확하다고 밝힘(ADR-001).
- 얻은 것: P1 1절 원칙 3 "예측하지 않는다"와 이름이 맞음.
- 출처: ADR-001 · P2 0절 `[확인]`

### C02 GPR 한국 = 정답 → 비교 지수
- 처음(P2 3·5절): GPR 한국 월별을 **정답으로 회귀**해 묶음 가중치 학습(OLS, Ridge 점검), 채점 ① 재현도 = GPR 맞히기.
- 지금: 비교 지수로만 쓰고 가중치를 GPR에 맞추지 않음.
- **왜:** GPR은 위협·확전만 세는 한쪽 방향 지수다. 2018년 정상회담 시기에 GPR 한국이 상위 2.5%까지 올라 회담·합의의 완화 효과를 학습할 수 없다 `[확인: ADR-002]`. G1 메모는 "이대로 회귀하면 회담·합의 묶음의 가중치는 음수가 아니라 양수로 나올 가능성이 높다"고 적었다 `[확인: G1 전처리메모 "정답으로 쓸 수 있는지 점검" 1번 — 메모 자체는 해석]`. 또 미국 언론이 덜 다룬 군사 위기를 놓친다 — 2015-08 목함지뢰(G1 메모 표기 "DMZ 지뢰도발", 위기 목록의 "2026-09 DMZ 지뢰"와 다른 사건) 31 백분위 `[확인: G1 메모 2번·표]`.
- 얻은 것: "관심(보도량)"이 아니라 "행동(사건)"을 재는 지수라는 차별점이 생김 — GPR과 다른 달은 "왜 다른지" 설명 자료가 됨(채점 v0 4절, 판독문).
- 대가: 가중치를 데이터로 정하는 길이 사라짐 → C03.
- 출처: ADR-002 · P2 3·5절 · `claude/G1_전처리메모.md` · `docs/tension/채점_v0_결과.md` 4절

### C03 가중치 = 학습 → 세부기준 점수 + 동일 가중
- 처음: P1 5절 ② 유형별 가중치표(핵실험 10 · ICBM 8 · 포격 7 …), 슬라이더로 조정 / P2 3절 묶음 가중치를 GPR 회귀로 학습, 전문가값보다 잘 맞으면 교체.
- 지금: **사건 점수 S = B × C**(B = 유형 기본점수 0~10, C = 세부 계수 0.75~1.25 가중평균, 상한 없음, 결측은 Null) — 팀 세부기준 시험안 값. 묶음 가중 ω = 동일(기본 1/3, 확장 1/4).
- **왜:** GPR 회귀를 버려(C02) 학습할 정답이 없음. 팀이 요소별 세부기준을 만들어 사건마다 점수를 매김(ADR-017).
- 얻은 것: 사건 1건의 점수 근거를 세부기준표로 설명 가능. 팀 설명자료 v1.0과 같은 공통식.
- 대가·공개: **B 값은 근거 자료 없이 정한 판단**(사용자 확인 10-28). 그래서 흔들기 점검 — 요소 B·묶음 가중 ±50% 1,000회에도 일별 단계 86~91%(중앙) 유지 → 판독문으로 공개(단계 5 V3 (가)).
- 출처: ADR-004 · ADR-017 · `docs/tension/단계5_값확정_결정자료.md` V3 · `docs/tension/채점_v0_결과.md` M5

## 2. 척도와 합치는 식

### C04 0~100 백분위 → 평소 = 100
- 처음(P1 5절 ④, P2 1절, P3): 과거 전체 기간 분포에서 오늘 값의 백분위(0~100)가 긴장 지수.
- 지금: **주 지수 = 평소 = 100**(기준기간 2010~2019 하루 평균을 묶음별로 100, 200 = 평소의 2배). 백분위는 카드 보조 문구 "2010년 이후 그날까지 기록 중 상위 x%"로만(표시선의 그날까지 누적 백분위).
- **왜(10-20 팀, 10-27 확정):** ① 백분위는 상한이 있어 큰 위기도 99 근처에서 멈춤(v0.1.2: 지수 572~1,058인 62일이 모두 99~100) ② 전체 기간 백분위는 과거 시점에 미래 자료가 섞이고, 새 자료가 들어오면 과거 값이 바뀜(2017 최고점 99.9 → 98.2) ③ "특정 상황 = 100"은 객관적 기준이 없고, "평소를 계속 재계산"하면 긴장이 길 때 평소가 따라 올라감.
- 얻은 것: 위기 크기 차이가 보임 · 한 번 낸 과거 값이 안 바뀜 · "평소의 몇 배"로 읽힘 · 코스피식 추세(C21)가 뜻을 가짐.
- 팀 정합: 팀 공유본(10-27 docx)이 0~100 백분위 설명을 "사용하지 않음"으로 정정.
- 기준기간 2010~2019 이유: 알려진 자료 문제가 가장 적고(A5 0건 2년, 2022년 이후 고밀도기 제외), 2010~2021·2012~2021과 위기 포착 같음. 한 번 정하면 다시 계산하지 않고 바꿀 때 버전을 올림(GDELT Atlas GPR 관행).
- 출처: ADR-003 · 개발 계획 2.1·2.6 · `docs/tension/S3_척도_단계_표시_결정자료.md` 3·5절

### C05 단순 합 → 묶음별 정규화형
- 처음: P3 팀 설명자료 v1.0은 모든 점수를 한 줄로 더함. 파일럿 "기본형" T = Σ dir·R ÷ 평균 × 100.
- 지금: 묶음마다 T_g = 100 · R_g / B_g, 상승 지수 T⁺ = 상승 묶음 T_g의 평균. (개발 계획 2.2의 "100 + Σω(T_g − 100)"과 Σω = 1이면 같은 값 `[해석: 식 전개]`)
- **왜:** 단순 합은 비중이 묶음의 평소 크기를 따라감 — 파일럿 임시 점수에서 미사일 평소 1.77이 물리 충돌 0.22의 8배 비중 → 연평도·목함지뢰를 한 단계 낮게 잡음, 2010년(천안함·연평도)이 지수 최저권.
- 얻은 것: 묶음끼리 같은 무게 · 점수 구성표("묶음별 몇 %")와 바로 연결.
- 대가: 평소값이 작은 묶음은 1점이 커짐(희귀 묶음 폭발 → C06).
- **지금 데이터에서의 크기(10-29 확인):** 상승 묶음 평소값이 2.55·2.55·2.32(확장 + 제재 3.26)로 비슷해, 정규화형과 단순 합의 차이가 작다 — 정규화 효과만 남긴 비교선(C18)이 T와 상관 0.9995 `[우리 데이터]`. 파일럿 때 차이가 컸던 묶음(물리·북러)은 이미 하한으로 빠졌기 때문 `[해석]`. ADR-005를 바꿀 일은 아니고 설명 거리.
- 출처: ADR-005 · `v0_파일럿_산출식_비교.md` 2·4절 · 개발 계획 1절·8.1

### C06 희귀 묶음 → 전용 하한
- 처음: 파일럿은 물리 충돌·북러 밀착도 다른 묶음처럼 정규화해 합산.
- 지금: 두 묶음은 T에서 빼고 "최소 몇 거" 하한으로만 단계에 반영.
  - 물리(A3·A7, 반가우스 30일 원점수): R ≥ 3 → 3거 · R ≥ 7 → 4거 · **4거 유형 사건 당일 4거**(MDL·NLL·영공 실제 침범, 쌍방 교전, 우리 측 사상자 — 판정표 Y 16건) · 오물풍선만 R ≥ 6 → 3거 · **사망·침몰 당일 5거**(천안함 A7-0098, 연평도 A7-0100)
  - E5 북러(군사 협력·합의·제도화): R ≥ 4 → 3거 · ≥ 10 → 4거
- **왜:** 기준기간 사건이 11~13건뿐이라 평소값이 0에 가깝고 사건 1건에 평소 대비가 수천으로 튐(파일럿). 그렇다고 빼기만 하면 천안함 1거·연평도 2거·목함지뢰 1거(v0.1.2). 북러는 "기준기간에 없던 새 현상".
- 얻은 것: 봉수 원뜻(3거 경계 접근 · 4거 경계 침범 · 5거 교전)을 하한이 맡음 → "무슨 일이 있었나"가 단계에 들어감(L5 혼합).
- 바뀐 경과: 4거 문턱 6 → 7(10-27, 팀 A7 점수가 모두 6.0 이상이라 포격 1건마다 4거가 되던 문제) → **4거 유형 규칙 추가**(10-28 V1 (e): 4거가 "A7 7.2 vs 문턱 7" 거리에 기대던 문제, 목함지뢰 4거 유지 55 → 100%) · 폭파는 경계를 넘지 않아 3거로 정정 · E5 하한은 10-27 한때 미사용 → 같은 날 복원.
- 대가: 규칙 3줄, 사망·침몰·4거 유형은 사람이 판정. 화면에서 "선은 낮은데 5거"가 생김(채점 W3 → 화면에 하한 근거 표시 필수).
- 출처: ADR-007·014 · 개발 계획 8.1 ⓒ-(b) · `docs/tension/S1_하한_완화_결정자료.md` · `docs/tension/단계5_값확정_결정자료.md` 1절

### C07 완화 = 빼기 → 곱하기 할인
- 처음: P2 "F2 한국 정부 대북 기조"를 수정자로 / 파일럿은 완화 묶음을 음수로 빼기, C4 대화·합의도 완화.
- 지금: T = T⁺ × (1 − min(c · R완 / B완, κ)), **c = 0.1 · κ = 0.5**. R완 = F2 남북 회담 S_보정(정치·군사 1.0 / 경제·인도·사회문화 0.2)의 반감기 14일 누적. C4는 쓰지 않음(팀 결정) → 완화 = F2만, 2019년 이후 0(실제 회담 없음).
- **왜:** 빼기는 2018년에 지수를 −347까지 내려 "음의 긴장"이 생김(660일 음수). 곱하기는 지수를 0 이상에 두고 완화를 "상승 효과의 할인"으로만 작용. c = 1(10-26 첫 값)은 경제 실무회담 1건도 상한에 닿아 켜짐/꺼짐처럼 동작했고 41일 전 실무접촉 때문에 4차 핵이 2거 → c = 0.1. 분야 보정은 정치·군사 회담은 많이, 경제·사회문화는 조금 깎게.
- 얻은 것: 장성급 이상 정치·군사 회담만 당일 최대 할인(50%), 사회문화 실무 3%.
- 대가: 상한에 붙는 날 272일(2018 정상회담기) — 단계에는 영향 없고 2018년 선 높이만(V4 견고성). 북미 정상외교는 지수 밖(판독문).
- 출처: ADR-008·009·015 · 개발 계획 8.1·8.4 · `docs/tension/S1_하한_완화_결정자료.md` 3절 · `docs/tension/단계5_값확정_결정자료.md` V4·V5

### C08 감쇠: 반감기 14일 → (파일럿 30일 창) → 반감기 14일, 끊지 않음

- 출처: ADR-006 · P1 5절 ③ · `docs/tension/감쇠_표시_단계유예_조사.md` 1·4절 · 개발 계획 8.5

### C18 비교선 T_basic = 정규화 효과만 (10-29)
- 처음: 파일럿 기본형 T_basic = Σ dir·R(7묶음, 완화 −) ÷ 기준기간 평균 × 100(`v0_파일럿\scripts\compute_v0.py` 54~56행) · ADR-005 "단순 합은 비교선으로 함께 그린다" · 산출식 1절 "T_basic = Σ R_g ÷ 기준기간 평균 × 100(묶음 구분 없이 단순 합)"(Σ 범위 표기 없음).
- 지금: **T_basic = 100 · Σ_{g∈G} R_g ÷ mean_{2010~2019}(Σ_{g∈G} R_g) × (1 − δ)**. G = 그 시나리오의 상승 묶음(기본 3 · 확장 4), δ = 주 지수와 같은 완화 할인. 분자 Σ R_g = 원점수(⑮). `run_tension`이 사건표로 계산해 `data/tension/비교선_일별.csv`로 커밋(일별·요약 CSV 계약은 그대로). 화면은 추이 그림이 아니라 **설명 자리(산출 방법)에 "묶음 정규화 효과" 그림 + 판독문 1줄**.
- **왜 이 정의인가:**
  1. 비교선의 목적은 "묶음별 정규화형(우리) vs 단순 합(기본형·팀 설명자료 v1.0)의 차이"를 보이는 것(ADR-005, 개발 계획 1절, 파일럿 2절 "기본형 = ω ∝ B_g로 둔 특수한 경우"). 그 차이만 남기려면 **나머지(묶음 구성·완화 처리)는 주 지수와 같게** 둬야 한다.
  2. 파일럿 원형을 그대로 쓰면 물리·북러(지금은 하한, C06)와 빼기 완화(지금은 곱하기, C07)가 다시 들어와 세 가지 차이가 섞이고, 음수 날이 생긴다(기본 428일).
  3. 완화를 빼고 할인을 안 곱하면(후보 (나)) 2018년 차이가 대부분 완화 할인 몫이 된다.
- 후보 비교(기본, 2010-01-01~2026-10-29, 커밋된 사건표, develop `04c5353` 코드) `[우리 데이터]`:

| 후보 | T와 상관 | T와 차 최대 | 음수 날 | 2018 평균(T 27.8) |
|---|---|---|---|---|
| **(나′) 채택** | 0.9995 | 22 | 0 | 26.6 |
| (나) 할인 없음 | 0.998 | 68 | 0 | 46.9 |
| (다) 완화 빼기 | 0.993 | 187 | 492 | −24.1 |
| (가) 파일럿 원형 | 0.932 | 433 | 428 | −22.2 |

- 얻은 것·뜻 `[해석]`: 지금 데이터에서는 정규화 효과가 작다(상승 묶음 평소값이 비슷). 파일럿에서 정규화형을 고른 이유(미사일 독주로 물리 충돌이 묻힘)는 물리 충돌을 하한으로 뺀 결정(C06)이 이미 대부분 해결했다. 이 사실이 "묶음 정규화 효과" 그림이 보여 줄 내용이다. 추이 그림에 넣으면 선이 겹쳐 정보가 늘지 않아 넣지 않음.
- 결론이 바뀔 조건: 묶음 구성이나 B가 바뀌어 상승 묶음 평소값이 크게 벌어지면 차이가 커진다 → 그때는 추이 그림 비교선을 다시 검토.
- 출처: 진행기록 1절 10-29 "T_basic 정의·화면·저장" · ADR-005 · `docs/tension/산출식_정리.md` 1절 43행·1A.5 · `docs/tension/채점_v0_결과.md` W13
