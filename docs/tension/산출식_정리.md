## 1. 전체 식

| 단계 | 식 | 지금 값 | 상태 |
|---|---|---|---|
| ① 사건 점수 | **S = B × C**. B = 유형 기본 점수(0~10), C = 세부 계수(0.75~1.25, 세부기준이 여럿이면 가중평균) | 상한 없음. 결측은 Null(0 아님) | ● |

| ③-하한 | 전용 하한(E5·물리)의 원점수는 **반가우스 σ10·30일 창 그대로** R = Σ_{k<30} exp(−k²/200)·d | 문턱(E5 4·10, 물리 3·7 · 풍선 6)이 30일 원점수에 맞춘 값이라 분리. 지수와 하한의 감쇠 규칙이 다름 | ● ADR-006·014 |

### 1A.2 식

```
① 사건 점수       S_i = B_i × C_i ,     C_i = Σ_k w_k · c_ik      (Σ_k w_k = 1 ,  0.75 ≤ c_ik ≤ 1.25)

② 일 합           d_g,t = Σ_{i : g(i) = g , t_i = t} S_i

③ 감쇠 누적       R_g,t = λ · R_g,t−1 + d_g,t ,     λ = 2^(−1/14) ≈ 0.9517 ,     R_g,(2009-12-31) = 0
                  (같은 식)  R_g,t = Σ_{k ≥ 0} λ^k · d_g,t−k

④ 평소값          B_g = (1 / |𝒯₀|) · Σ_{t ∈ 𝒯₀} R_g,t

⑤ 평소 대비       T_g,t = 100 · R_g,t / B_g

⑥ 상승 지수       T⁺_t = (1 / |G|) · Σ_{g ∈ G} T_g,t

⑦ 완화 할인       R^완_t = λ · R^완_t−1 + Σ_{i ∈ F2 , t_i = t} φ_i · S_i
                  δ_t = min( c · R^완_t / B^완 ,  κ ) ,     c = 0.1 ,  κ = 0.5 ,  φ_i ∈ {1.0 , 0.2}

⑧ 긴장도(주 지수) T_t = T⁺_t · (1 − δ_t)

⑨ T 구간 단계     θ_j = ⌊ Q_{p_j}( { T_s : s ∈ 𝒯₀ } ) ⌉ ,     (p₁, p₂, p₃, p₄) = (0.70, 0.90, 0.95, 0.98)
                  L^T_t = 1 + Σ_{j=1..4} 𝟙[ T_t ≥ θ_j ]

⑩ 전용 하한       ρ_t(x) = Σ_{k=0..29} exp(−k² / 200) · x_t−k              (반가우스 σ = 10, 30일 창)

                  물리   F^물_t = 5   t가 사망·침몰 사건일(A7-0098 천안함, A7-0100 연평도)
                                 4   ρ_t(d^물) ≥ 7  또는  t가 4거 유형 사건일(판정표 Y: 침범·교전·사상자)
                                 3   ρ_t(d^물) ≥ 3  또는  ρ_t(d^풍) ≥ 6
                                 1   그 외
                  북러   F^E5_t = 4 (ρ_t(d^E5) ≥ 10) ,  3 (ρ_t(d^E5) ≥ 4) ,  1 (그 외)
```

### 1A.4 사건 1건이 지수에 주는 몫

k일 전 사건 i 한 건이 오늘 T에 더하는 양(다른 조건이 같을 때):

```
ΔT_t = 100 · S_i · λ^k / ( |G| · B_g(i) ) · (1 − δ_t)
```

예(v0.1.3 기본, δ = 0) `[우리 데이터]`: ICBM(S 7.5) → 당일 +97.9, 14일 뒤 +48.9 · 위협 성명 C1(S 6.25) → 당일 +89.9. 평소값 B_g가 작은 묶음일수록 1점이 커진다. 이것이 ÷ B_g의 의도(미사일 묶음 독주 방지)이자 주의할 점이다.

### 1A.5 식에서 생기는 주의점
- B_g와 θ_j는 같은 기준기간에서 나오므로 입력이 바뀌면 둘 다 다시 뽑아야 한다(규칙은 고정, 값은 버전마다 다름).

## 3. 요소별 가중치는 어떻게 나오나

가중치를 요소마다 따로 정하지 않는다. **세 겹으로 정해진다.**

```
사건 1건이 지수에 주는 몫 =  S (요소 안 기준: B × C)
                          ×  100 ÷ B_g (묶음의 평소값으로 나눔 — 자동)
                          ×  ω_g (묶음 가중 — 동일)
```

| 겹 | 누가 정하나 | 지금 |
|---|---|---|
| ① 요소 안: 사건마다 S = B × C | 세부기준표(4절) | 요소마다 B 척도가 다름 → 요소 간 크기 차이도 여기서 생김 |
| ② 묶음 정규화: ÷ B_g | 기준기간 데이터가 자동으로 | 평소 사건이 많은 묶음일수록 1점의 값이 작아짐 |
| ③ 묶음 가중: ω_g | 사람이 정함 | 동일 가중(1/3 또는 1/4). 조정 절차 M1~M5는 v0.1 뒤 |

같은 묶음 안의 요소끼리는 **점수 합의 비율대로** 묶음 몫을 나눠 갖는다. 예를 들어 핵·미사일 묶음 안에서 A2가 기준기간 점수의 80%를 차지하면, 그 묶음 몫의 80%가 A2에서 나온다.

### 점수 1점이 상승 지수 T₊를 얼마나 올리나 `[임시: 파일럿 평소값 기준]`
| 묶음 | 평소 B_g (파일럿) | 기본(ω = 1/3) | 확장(ω = 1/4) |
|---|---|---|---|
| 핵·미사일 | 1.77 | **+18.8** | +14.1 |
| 군사 과시 | 1.14 | **+29.2** | +21.9 |
| 위협 언어·교리 | 0.43 | **+77.5** | +58.1 |
| 제재·압박 | 0.58 | — | +43.1 |

→ 동일 가중이어도 **위협 언어 1점이 미사일 1점의 약 4배**로 들어간다. 평소 사건이 적은 묶음일수록 1점이 크게 작용하기 때문이다. 이것이 정규화형의 의도(미사일 묶음 독주 방지)이지만, 위협 언어 묶음이 과하게 출렁이는지 v0.1에서 꼭 확인해야 한다. 파일럿 평소값은 임시 점수와 C4 결렬을 포함한 값이라 v0.1에서 다시 나온다.
- **확정 입력 기준(10-27, S2 최종):** 1점이 T₊를 올리는 크기 핵·미사일 8.8 · 군사 과시 13.1 · 위협 언어·교리 14.4 → **위협 언어 1점 ≈ 미사일 1점의 1.6배**(파일럿 4배에서 줄어듦; 묶음 평소값 3.80 · 2.55 · 2.32). C3 1건(평균 5.4점) ≈ T₊ +78.
- **v0.1.3(10-28, A2 같은 날 1회):** 핵·미사일 13.1 · 군사 과시 13.1 · 위협 언어·교리 14.4 → 세 묶음 1점 무게가 거의 같아짐(위협 언어 ≈ 미사일의 1.1배).
