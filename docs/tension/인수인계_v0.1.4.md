## 7. 작업 규칙 (지시서 00 + 이번에 생긴 것)
- 원본 보호: `data\raw\` 원본, `입력사본`, E5 점수표 v1은 수정하지 않는다. 바꿀 일이 생기면 새 판 파일을 만든다.
- 다른 세션이 같은 문서를 동시에 고칠 수 있다. 고치기 직전에 다시 읽고, 정확히 1회 일치하는 문장만 바꾼다. 다른 세션이 쓴 줄은 지우지 않는다.
- 결정 전에는 ADR·산출식 정리를 고치지 않는다. 판단할 지점은 반드시 물어보고, 그때마다 복사용 답변 템플릿을 붙인다.
- 문서를 바꾸면 연결 폴더와 프로젝트 문서를 둘 다 맞춘다.
- 모델 권장: v0.1.3 계산·검산·분해는 **Opus 5.5, 노력 수준 높음**. 문서 반영만 할 때는 Sonnet 5.5, 노력 수준 보통.
